# 🧠 Bridge Crack Detection using Convolutional Neural Networks (CNN)

> Learning Convolutional Neural Networks through a real-world computer vision project using PyTorch.

---

## 📖 Overview

This repository documents my journey of learning **Convolutional Neural Networks (CNNs)** while building a **Bridge Crack Detection** model. The project focuses on understanding the core concepts of deep learning and applying them to detect cracks in bridge images.

The goal is not only to build an accurate model but also to understand how CNNs work from the ground up.

---

## 🎯 Objectives

- Learn the fundamentals of CNNs
- Understand image processing for deep learning
- Build CNN models using PyTorch
- Train and evaluate image classification models
- Apply CNNs to bridge crack detection
- Document the learning process and experiments
